# クレープ注文（レジ・受け渡し口の2台用）

文化祭のクレープ屋（チョコ・あんこ）で、iPad 2台の数を共有するアプリです。

- **レジのiPad**（`register.html`）: 注文を受けたら味のパネルをタップ。今日の売上の累計が大きく出ます。
- **受け渡し口のiPad**（`pass.html`）: 受け取り待ちの個数が大きく出ます。渡したら味のパネルをタップすると1個減ります。

数は Firebase（Google の無料サービス）に日付ごとに保存され、もう1台にすぐ反映されます。
**2台ともネットにつながっている必要があります。** 一瞬切れても、つながり直すと反映されます（画面右上に状態が出ます）。

## ボタン
| iPad | 操作 | 意味 |
|---|---|---|
| レジ | パネルをタップ | 注文 +1（売上 +1、受け取り待ち +1） |
| レジ | 「注文を1個取り消す」 | 押し間違いを戻す（まだ渡していない分だけ） |
| レジ | 「今日の数をリセット」を2回 | 今日の数を2台とも 0 に戻す（練習で数えた分を消すとき） |
| 受け渡し口 | パネルをタップ | 1個渡した（受け取り待ち −1） |
| 受け渡し口 | 「渡した」を1個取り消す | 押し間違いを戻す |

日付が変わると、自動で新しい日の数（0から）になります。前の日の数も Firebase に残ります。

## Firebaseの準備（最初に1回だけ）
1. https://console.firebase.google.com/ を Google アカウントで開き、「プロジェクトを作成」（名前は例: `bunkasai-crepe`。Google アナリティクスはオフで大丈夫）
2. 左のメニュー「構築」→「Realtime Database」→「データベースを作成」
   - 場所: **シンガポール（asia-southeast1）**
   - 「ロックモードで開始」を選ぶ
3. 「ルール」タブを開き、このリポジトリの `database.rules.json` の中身をまるごと貼り付けて「公開」
4. 歯車（プロジェクトの設定）→「マイアプリ」の `</>`（ウェブ）→ 名前を付けて登録（Hosting はチェックしない）
5. 出てきた `const firebaseConfig = { ... }` の中身を、`firebase-config.js` の `window.FIREBASE_CONFIG = null;` の `null` と置き換える
   - `databaseURL` が入っていることを確かめる（なければ Realtime Database の画面上部の `https://...firebasedatabase.app` を追加）

ルールで、読み書きできるのは `crepe/日付/` の数だけにしています。URL を知っている人は数を変えられるので、URL は係の人だけで共有してください。

## iPadでの準備
1. Safariで https://masatakai1011-lab.github.io/bunkasai-counter/ を開き、「レジ」または「受け渡し口」を選ぶ
2. 共有ボタン（□に↑）→「ホーム画面に追加」
3. 右上が「● つながっています」になるのを確かめる
4. レジでタップ → 受け渡し口に数が出る → 受け渡し口でタップ → レジの「受け取り待ち」が減る、を試す
5. 試した分は、レジの「今日の数をリセット」を2回押して 0 に戻す

## 直すとき
ファイルを変えたら、`sw.js` の `VERSION` を変えてください。iPadはネットにつながっていれば、開くたびに新しいファイルを取りに行きます。
