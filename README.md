# チョコあんこカウンター

文化祭で、チョコとあんこの売り上げ個数を1個ずつ数えるiPad用アプリです。
ホーム画面に追加すると、Wi-Fiがなくても動きます。数はiPadの中に保存されます。

## 使い方
- **注文 +1**: 注文を受けたら押す。「作り待ち」が1増える
- **パネルを大きくタップ**: お客さんに渡したら押す。売上が1増え、作り待ちが1減る
- **注文 −1**: 注文の取り消し
- **売上を1個減らす**: 押し間違えたとき。作り待ちから渡した分なら、作り待ちも元に戻る
- 画面の上に、合計の売上と作り待ちの合計が出ます

## iPadでの準備（文化祭の前に、ネットのある場所で）
1. Safariで https://masatakai1011-lab.github.io/bunkasai-counter/ を開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」
3. ホーム画面の「カウンター」を、ネットがある状態で一度開く
4. 右上に「ネットなしでも動きます」と出るのを確かめる
5. 機内モードにして、アプリを閉じて開き直し、動くか試す
6. 試しに数えた分は「リセット」で0に戻す

注意: Safariで数えた数は、ホーム画面のアプリには引き継がれません。当日はホーム画面のアプリで数えてください。

## 注文の作り待ちだけを数えるページ
https://masatakai1011-lab.github.io/bunkasai-counter/orders/ を開き、上と同じように「ホーム画面に追加」します（アイコン名は「注文」）。
- **パネルをタップ**: 注文を受けたら押す。作り待ちが1増える
- **1個 渡した**: 渡したとき、または注文を取り消したときに押す。作り待ちが1減る
- 画面の上に、作り待ちの合計と、これまでに渡した個数が出ます

## 直すとき
ファイルを変えたら、`sw.js`（注文ページなら `orders/sw.js`）の `VERSION` を1つ上げてください（iPadに新しい版が届くようにするため）。
