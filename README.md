# チョコあんこカウンター

文化祭で、チョコとあんこの売り上げ個数を1個ずつ数えるiPad用アプリです。
ホーム画面に追加すると、Wi-Fiがなくても動きます。数はiPadの中に保存されます。

## iPadでの準備（文化祭の前に、ネットのある場所で）
1. Safariで https://masatakai1011-lab.github.io/bunkasai-counter/ を開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」
3. ホーム画面の「カウンター」を、ネットがある状態で一度開く
4. 右上に「ネットなしでも動きます」と出るのを確かめる
5. 機内モードにして、アプリを閉じて開き直し、動くか試す
6. 試しに数えた分は「リセット」で0に戻す

注意: Safariで数えた数は、ホーム画面のアプリには引き継がれません。当日はホーム画面のアプリで数えてください。

## 直すとき
ファイルを変えたら、`sw.js` の `VERSION` を1つ上げてください（iPadに新しい版が届くようにするため）。
